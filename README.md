# Chandan Kumar B N — Personal Portfolio

A responsive, static portfolio website presenting selected product, project-delivery, business-analysis, and technology work.

## Contents
- `index.html` — complete single-page portfolio website.
- `assets/photo.jpg` — profile photograph supplied with the portfolio.
- `favicon.svg` — browser tab icon.
- `vercel.json` — static hosting headers and caching configuration.

## Run locally
No build step, package installation, or framework runtime is required. Open `index.html` in a browser or serve the repository root with any static file server.

## Deploy on Vercel
1. Import [Chan0304/chandan-portfolio](https://github.com/Chan0304/chandan-portfolio) into Vercel.
2. Select the **Other** framework preset.
3. Leave Build Command and Output Directory empty.
4. Deploy from the repository root.

## Editing
Project content is maintained in the `P` array near the bottom of `index.html`. Supporting document links are maintained in the `L` object.

Keep project descriptions evidence-based. Never publish confidential client, customer, patient, vendor, or employee information, credentials, private API keys, or internal-only documents.
